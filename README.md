# 一字一练

在线使用：https://zitie.denghanjie.vip

源码：https://github.com/denghanjie/zitie

部署说明：[deploy/README.md](deploy/README.md)

本地汉字练习字帖网站。双击 `启动网站.command` 即可在 Mac 的浏览器打开（需要 Python 3，本机已具备）。使用时保留终端窗口；关闭窗口会停止网站。无需联网、无需账号，所有字形与依赖已经随 dist 打包。

1. 粘贴汉字、段落或文章，最多 3000 个字符。
2. 选择逐字练习或整篇临摹、田字格或米字格。
3. 点击「生成字帖」，检查分页预览。
4. 点击「保存 PDF」直接下载 A4 文件，或者点击「打印」。打印选择 A4、纵向、100% 比例，关闭页眉页脚。

逐字模式只提取汉字，按原顺序保留重复字，每个字一行六格，第一格深色范字、后五格浅色描红；下方显示带编号的累计笔顺。整篇模式保留标点、空格与段落，不显示笔顺。

笔顺数据为本地 hanzi-writer-data 2.0.1 / Make Me a Hanzi 字库。未收录的字保留并使用系统字体，明确标记缺少笔顺；极少见字能否显示取决于系统字体。字库许可见 public/ARPHICPL.TXT。输入文字与设置存储在浏览器 localStorage，没有上传接口。

PDF 为高分辨率页面图片，字形不依赖接收者安装中文字体；网页与浏览器打印使用矢量字形。浏览器打印「另存为 PDF」可保留矢量。

## 开发

React + Vite，运行 `pnpm install`、`pnpm dev`；构建 `pnpm build`。`dist/` 为可直接部署的静态网站（根路径部署）。

## 诗词自适应排版

整篇模式支持长短句、分阕与长篇古诗。可在「内容排版」中选择自动识别、诗词或文章。自动识别采用格式与句长规则，并非文学语义判断；识别不合适时可手动覆盖。

「诗词断句」支持：
- 自动：优先保留已经分行的诗句；一整段连续文本或按整阕粘贴的长段落，按标点断句。
- 完全保留原有分行：保留你指定的句组，仅在一行太长时折行。
- 按标点分句：按逗号、句号、问号等断句，同时保留空行分阕。

直接在输入框编辑换行；空一行标记上下阕或诗节。不会自动编造作品的阕界。诗词最多每行十二格，短句只画实际需要的格子，长句优先在标点处折行，并避免常见标点出现在行首。字格保持至少约 13.8 毫米；中等长度的诗节会适当缩小格子，尽量完整放在一页。放不下的长诗节按原句顺序分页。篇幅过长的一句必要时跨页。预览、打印和 PDF 共用同一排版。

验证：`node tests/layout.test.mjs`。测试覆盖《如梦令》《水调歌头》《梦游天姥吟留别》的三种断句方式、连续粘贴、内容不丢失、长句换行、分阕分页、标点避头、三千字输入以及原有文章和逐字模式。当前测试文本默认生成页数依次为 1、2、4 页；页数随输入换行与断句选项变化。浏览器已检查《水调歌头》下阕完整位于第二页，并测试两页 PDF 生成。
